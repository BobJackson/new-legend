# 热血传奇 (Legend of Mir 2.5D ARPG)

经典复古 2.5D ARPG 网页游戏，完美还原热血传奇的核心玩法与怀旧体验。支持战法道三职业、智能挂机巡逻、装备爆装与强化、坐骑神兽系统、天气地形交互以及沙巴克攻城等核心玩法。

---

## 🌟 游戏核心特色

### 1. 经典三职业体系
- **战士 (Warrior)**：高血量高防御，近战爆发，拥有攻杀剑术、刺杀剑術、野蛮冲撞、烈火剑法等经典技能。
- **法师 (Mage)**：远程群体高伤，拥有火球术、抗拒火环、疾光电影、地狱雷光、冰咆哮与魔法盾。
- **道士 (Taoist)**：辅助与召唤大师，拥有灵魂火符、施毒术、治愈术、隐身术以及召唤神兽/骷髅。

### 2. 2.5D Isometric 渲染引擎
- **高质感地形环境**：支持高山流水、黄土高坡、深山老林、汪洋大海与沙漠沉船等多样地形。
- **动态光照与天气系统**：支持晴天、阴雨、大雪、雷暴、迷雾与沙尘暴等天气特效，影响战斗环境与视觉感受。
- **细腻人物与战斗动画**：基于 Canvas 高性能帧级渲染，包含步行动画、施法光效、刀光剑影、击退震屏与暴击数字。

### 3. 智能挂机与自动寻航
- **流畅寻怪机制**：自动选择最佳路径寻怪与巡逻，遇到障碍物或无法到达的怪物时可智能绕路或平滑切换目标。
- **智能过滤拾取**：支持按装备品质（普通、精良、稀有、史诗、传说）及物品类型（金币、药水、材料、装备）自定义自动拾取。
- **安全保护设定**：支持生命/魔法值过低时自动使用药水、自动使用随机传送卷与回城卷。

### 4. 丰富装备与玩法系统
- **爆装与自由换装**：怪物与 Boss 掉落海量装备，支持装备强化、幸运裁决、祝福油与词条鉴定。
- **坐骑与神兽系统**：多阶坐骑（马匹、战狼、猛虎、祥龙等）提升移动速度与属性加成。
- **经典副本与 Boss 挑战**：比奇省、蛇谷、石墓阵、祖玛寺庙、赤月恶魔与沙巴克城堡。

## 🛠️ 技术栈

- **前端 React 19** + **TypeScript**
- **构建工具 Vite 6** + **Tailwind CSS 4**
- **服务端 Node.js / Express** + **tsx**
- **渲染引擎 HTML5 Canvas (Isometric 2.5D Engine)**
- **动画与 UI** Motion + Lucide React Icons

---

## 🚀 快速启动

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

打开浏览器访问 `http://localhost:3000` 即可体验游戏。

### 3. 生产打包

```bash
npm run build
npm start
```

## 🎮 操作说明

- **移动 / 攻击**：鼠标左键点击地图位置移动，点击怪物进行普通攻击/锁定。
- **快捷键技能**：数字键 `1` - `6` 触发对应槽位技能。
- **挂机控制**：点击 UI 上的 **【自动挂机】** 按钮或快捷键 `A` 开启/关闭智能挂机。
- **背包与角色**：点击界面下方菜单打开角色面板、背包、技能树与设置。
