# 热血传奇 (Legend of Mir 2.5D ARPG Web Engine)

一款基于纯前端技术栈打造的**高保真 2.5D 动作角色扮演游戏**。完全使用 React 19、TypeScript 和原生 HTML5 Canvas 构建，无缝还原了经典怀旧游戏《热血传奇》的核心体验。

最近更新引入了**高性能双层缓冲渲染（Bitmap Caching）**、**动态天气环境遮罩**以及**角色骨骼/面部拓扑渲染优化**，极大提升了画面质感与运行帧率。

---

## 🌟 引擎与技术亮点

### 1. 高性能 2.5D Isometric Canvas 渲染引擎
- **Terrain Bitmap Caching (地形位图缓存)**: 采用底层分层渲染与缓存技术，只在摄像机大范围移动或地形刷新时重新生成 2.5D 菱形地形网格，将复杂的坐标变换与光影计算压力降到最低，实现丝滑 60FPS。
- **环境遮罩与动态材质 (Dynamic Ground Effects)**: 
  - 雨天会在地面产生积水水坑（Puddles）并伴随动态波纹特效。
  - 草地环境风吹过会有落叶飘落的物理环境感，拒绝静态死板的背景。
  - 角色移动会在泥地与水中产生动态足迹（Footprints）与水波纹（Ripples）。
- **自然有机地形 (Organic Terrain Generation)**: 基于宏观与微观柏林噪声（Perlin Noise）生成无缝拼接地形、动态水面焦散特效（Caustics），彻底消灭了传统 2D 游戏生硬的棋盘格边缘。

### 2. 纯代码角色渲染与骨骼系统
- **Procedural Character Renderer**: 不依赖外部静态 Sprite Sheet（精灵图），使用 `CanvasRenderingContext2D` 的动态曲线与渐变渲染角色各部位躯干，实现丝滑的关节连接（去除拼接缝隙与生硬描边）。
- **Facial Depth Map & Tessellation Shader**: 通过 2.5D 深度映射计算眉骨、眼窝、鼻梁的立体光影，构建逼真立体的角色面部轮廓。
- **动态装备可视化**: 角色随着更换不同武器、头盔、铠甲，会实时改变外观建模、金属材质的高光反射，甚至会有各职业专属的光效（如战士重压、法师元素球、道士灵符）。

## ⚔️ 核心玩法体系

### 1. 经典三职业
- **战士 (Warrior)**：近战物理爆发。拥有攻杀剑术、刺杀剑術、野蛮冲撞、烈火剑法等。
- **法师 (Mage)**：远程魔法范围伤害。拥有火球术、抗拒火环、疾光电影、地狱雷光、冰咆哮与魔法盾。
- **道士 (Taoist)**：辅助与召唤。拥有灵魂火符、施毒术、治愈术、隐身术以及召唤神兽/骷髅。

### 2. 智能挂机系统 (Auto-Battle Engine)
- **智能寻路与索敌**：通过优化算法自动寻找最近的怪物，避开障碍物与无法攻击的目标。
- **高级过滤拾取**：支持按物品品质（普通至传说）与物品类别（装备、材料、药水等）进行自定义自动拾取设置。
- **生存保护**：血量/魔法值阈值自动吃药、随机飞随机传送卷、背包满自动回收或回城功能。

### 3. 丰富的成长与挑战
- **装备强化**：打怪掉落，自由换装。支持武器强化、幸运值提升与极品词条鉴定。
- **坐骑与宠物**：可捕捉并骑乘各种拉风坐骑（如战狼、猛虎、祥龙），提升机动性与角色属性。
- **经典地图体系**：还原比奇城、蛇谷、僵尸洞、祖玛寺庙、赤月祭坛与沙巴克城池等不同主题的挑战副本。

## 🛠️ 技术栈

- **前端**: React 19 + TypeScript + HTML5 Canvas API
- **UI & 样式**: Tailwind CSS 4 + Framer Motion (动画) + Lucide React (图标)
- **构建与开发**: Vite 6 + ESBuild
- **服务端 (Full-Stack)**: Node.js + Express (内置以支撑全栈架构与服务器端交互)

## 🚀 快速启动

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```
打开浏览器访问 `http://localhost:3000` 即可在本地体验游戏。

### 3. 生产打包部署
```bash
npm run build
npm start
```

## 🎮 操作说明

- **移动 / 攻击**：鼠标左键点击地图进行寻路，点击怪物进行普通攻击并自动锁定。
- **释放技能**：键盘数字键 `1` - `6` 触发技能栏对应的法术。
- **智能挂机**：点击界面下方的 **【自动挂机】** 按钮或按快捷键 `A` 开启/关闭。
- **系统菜单**：底部主菜单栏可唤出 **角色属性**、**背包仓库**、**技能树**、**坐骑** 与 **游戏设置** 面板。
